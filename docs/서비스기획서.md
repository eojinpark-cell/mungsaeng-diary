# 멍생일기 서비스 기획서

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 멍생일기 |
| 한 줄 소개 | 아기 강아지부터 무지개다리까지, 한 강아지의 일생을 함께하는 웹 게임 |
| 목적 | 강아지를 키우고 싶지만 키울 수 없는 사람, 또는 떠나보낸 강아지를 그리워하는 사람이 짧은 시간 동안 한 생애를 함께하며 위로와 따뜻함을 느끼게 한다 |
| 타겟 사용자 | 강아지를 좋아하는 20~30대, 반려견을 키우고 싶지만 여건이 안 되는 직장인·학생 |
| 제공 가치 | ① 짧은 플레이(약 5분)로 일생을 경험 ② AI가 나이·기분에 맞춰 대답해 살아 있는 느낌 ③ 엔딩에서 강아지가 쓴 편지로 감정적 마무리 |

## 2. 페이지 구성 및 메뉴 이동

상단 고정 메뉴(모바일은 '메뉴' 버튼으로 펼침)로 4개 페이지를 오간다.

| 페이지 | 파일 | 주요 내용 |
|---|---|---|
| 처음으로 | index.html | 서비스 소개, 생애 5단계 안내, AI 대화 예시, 입양 버튼 |
| 키우기 | game.html | 입양, 돌보기, 성장, AI 말 걸기, 무지개다리 엔딩, AI 편지 |
| 추억 앨범 | album.html | 추억 타임라인, 하늘나라 강아지 목록과 편지 |
| 도움말 | help.html | FAQ, 기록 초기화 |

## 3. 핵심 기능

1. **입양:** 이름(필수, 10자 이내)과 털 색(크림·초코·눈송이) 선택
2. **돌보기 5종:** 밥 주기, 산책, 공놀이, 목욕, 낮잠. 누를 때마다 상태(배부름·행복·건강·청결)가 변하고 시간이 흐름(첫 1년은 1개월, 이후 6개월씩)
3. **성장:** 아기 → 꼬마 → 어른 → 노견. 단계마다 하늘 색, 강아지 크기, 노견의 흰 눈썹·주둥이 등 모습 변화. 1살·3살 생일 등 추억 자동 기록
4. **무지개다리:** 13~16살 사이 무작위 수명에 도달하면 밤하늘과 무지개, 천사 날개를 단 강아지가 나타남. 돌봄이 부족해도 일찍 떠나지 않음(불필요한 상실감 방지)
5. **AI 말 걸기 / AI 하늘나라 편지** (아래 4장)
6. **추억 앨범:** 기록을 브라우저에 저장하고 하늘나라 강아지들을 모아 보여줌

## 4. AI 기능 설계

### 4-1. 말 걸기

| 구분 | 내용 |
|---|---|
| 입력 | 보호자의 말(필수, 200자 이내) + 자동 첨부: 강아지 이름, 나이 단계, 나이, 현재 상태 수치 |
| 처리 | 서버(`api/dog.py`)가 단계별 말투 규칙(아기: 서툰 말, 노견: 느긋하고 다정)과 상태 반영 규칙을 붙여 Gemini 호출 |
| 출력 | 강아지 시점의 반말 답장 2~3문장, 이모지 1개 이내. 상태가 낮으면 티를 냄(예: 배고프다) |
| 사용자 가치 | 같은 말을 해도 나이와 기분에 따라 다르게 대답해 강아지가 살아 있는 느낌 |

### 4-2. 하늘나라 편지

| 구분 | 내용 |
|---|---|
| 입력 | 버튼 클릭 + 자동 첨부: 이름, 추억 목록(최대 12개), 가장 많이 한 돌봄 |
| 출력 | 6문장 이내 편지, 고마움과 "여기서 잘 지내"는 따뜻한 톤, 마지막 줄 "- 이름 올림" |
| 사용자 가치 | 플레이한 기록이 반영된 나만의 엔딩 |

### 4-3. 실패 처리 기준

| 상황 | 기준 | 사용자 안내 |
|---|---|---|
| 빈 입력 | 공백만 입력 | "강아지에게 할 말을 먼저 적어 주세요." (서버 요청 안 함) |
| 지연 | 8초 이상 응답 없음 | "조금 오래 걸리고 있어요. 그대로 기다려 주세요." |
| 타임아웃 | 25초(브라우저) / 20초(서버) | "응답이 25초 넘게 오지 않아 멈췄어요. 잠시 후 다시 시도해 주세요." |
| API 오류 | Gemini 4xx/5xx | "AI 서버 오류가 났어요(코드 N). 잠시 후 다시 시도해 주세요." |
| 사용량 초과 | 429 | "오늘 강아지가 말을 너무 많이 했어요. 조금 쉬었다가 다시 시도해 주세요." |
| 빈 응답 | 응답에 텍스트 없음 | "강아지가 대답을 못 했어요. 다른 말로 다시 걸어 주세요." |
| 키 미설정 | 환경 변수 없음 | "서버에 AI 키가 설정되지 않았어요." |

### 4-4. 테스트 케이스

| 입력 | 기대 결과 |
|---|---|
| 아기 강아지에게 "안녕?" | 서툰 말투의 짧은 답장 표시 |
| 배부름이 낮은 상태에서 "기분 어때?" | 배고프다는 내용이 섞인 답장 |
| 빈칸으로 말 걸기 | 빨간 안내 문구, 요청 전송 안 됨 |
| 200자 가까운 긴 입력 | 답장 표시 또는 지연 안내 표시 |
| 무지개다리 후 편지 받기 | 추억이 반영된 편지가 표시되고 추억 앨범에 저장 |

## 5. 운영 고려사항

- API 키는 Vercel 환경 변수로만 관리, 코드·README·스크린샷에 노출하지 않음
- 무료 API 사용량 한도를 고려해 시간 경과(돌보기)는 AI를 호출하지 않고, 말 걸기·편지에만 AI 사용. 요청 후 2초간 버튼 비활성화
- 사용자 입력은 서버에 저장하지 않음
