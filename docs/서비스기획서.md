# 멍생일기 서비스 기획서

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 멍생일기 |
| 한 줄 소개 | 아기 강아지부터 무지개다리까지, 한 강아지의 일생을 함께하는 웹 게임 |
| 목적 | 강아지를 키우고 싶지만 키울 수 없는 사람, 또는 떠나보낸 강아지를 그리워하는 사람이 짧은 시간 동안 한 생애를 함께하며 위로와 따뜻함을 느끼게 한다 |
| 타겟 사용자 | 강아지를 좋아하는 20~30대, 반려견을 키우고 싶지만 여건이 안 되는 직장인·학생 |
| 제공 가치 | ① 짧은 플레이(약 5분)로 일생을 경험 ② AI가 나이·기분에 맞춰 대답해 살아 있는 느낌 ③ 엔딩에서 강아지가 쓴 편지로 감정적 마무리 |

## 2. 페이지 구성 및 메뉴 이동

상단 고정 메뉴(모바일은 '메뉴' 버튼으로 펼침)로 4개 페이지를 오간다.

| 페이지 | 파일 | 주요 내용 |
|---|---|---|
| 처음으로 | index.html | 서비스 소개, 생애 5단계 안내, AI 대화 예시, 입양 버튼 |
| 키우기 | game.html | 입양, 돌보기, 성장, AI 말 걸기, 무지개다리 엔딩, AI 편지 |
| 추억 앨범 | album.html | 추억 타임라인, 하늘나라 강아지 목록과 편지 |
| 도움말 | help.html | FAQ, 기록 초기화 |

## 3. 핵심 기능

1. **입양:** 얼굴 4종 × 털 색 3종을 미리보기로 고르고 이름 입력
2. **돌보기 5종 (시간이 흐름):** 밥 주기, 산책, 공놀이, 목욕, 낮잠. 각각 전용 연출(밥그릇, 지나가는 풍경, 날아오는 공, 욕조와 거품, 밤하늘)과 효과음이 있고, 나이에 따라 효과가 다름. 첫 1년은 2개월, 이후 8개월씩 시간 경과(한 생애 약 20번)
3. **함께 놀기 (시간이 흐르지 않음):** 쓰다듬기, 짖게 하기(나이별 다른 소리), 소리 켜기/끄기·음량 조절
4. **훈련:** 앉아(아기부터), 손·엎드려(꼬마부터). 기분과 연습량에 따라 성공률 상승, 정해진 횟수 성공 시 재주 습득
5. **표정과 모습:** 상태에 따라 9가지 표정, 청결이 낮으면 흙 얼룩. 단계마다 체형·소품·하늘 색이 다르고, 산책·공놀이 때는 옆모습으로 걷고 달림
6. **무지개다리 엔딩 5종:** 13~16살 무작위 수명에 도달하면, 평생 돌봄 점수·재주·콤보·돌봄 종류에 따라 황금/꽃길/구름 산책길/별빛/보슬비 중 하나를 건넘. 엔딩마다 하늘 색과 편지 톤이 다르고, 앨범에 수집됨. 돌봄이 부족해도 일찍 떠나지 않음(불필요한 상실감 방지)
7. **추억 앨범:** 추억 타임라인, 성장 일기, 업적, 하늘나라 강아지들과 편지 보관
8. **대화 게임:** 답장마다 AI가 감정·다정함 점수를 매겨 친밀도(5단계)·행복·뼈다귀가 오름. 오늘의 주제 단어를 쓰면 보너스
9. **퀘스트:** 한 번에 하나씩 진행, 완료 시 보상 후 다음 퀘스트
10. **살아 있는 강아지:** 시키지 않은 개인기와 사고(응가·양말 훔치기 등)를 스스로 함. 오랜만에 방문하면 외로워해서 달래 줘야 함
11. **보상·상점:** 돌봄 상태에 따른 뼈다귀 보상, 콤보(최대 3배), 황금 뼈다귀(8%), 공 잡기 미니게임, 업적 15종 → 상점에서 집·옷·모자 구매 후 바로 적용

## 4. AI 기능 설계

| 기능 | 입력 | 출력 | 사용자 가치 |
|---|---|---|---|
| 말 걸기 | 보호자의 말(필수, 200자) + 이름·나이 단계·상태·오늘의 주제 | 2문장 답장 + 감정 + 다정함 점수 0~3 (JSON) | 다정하게 말할수록 친밀도·보상이 오르는 대화 게임 |
| 성장 일기 | 단계 변화 시 자동: 이름·나이·최근 추억 | 강아지 시점 3문장 일기 | 성장을 기록으로 남김 |
| 랜덤 이벤트 | 돌보기 4번마다 50%: 이름·나이·상태·최근 추억 | 상황 2문장 + 선택지 2개 + 결과·상태 변화(±15 이내) (JSON) | 매번 다른 일상, 선택의 재미 |
| 하늘나라 편지 | 추억 목록, 가장 좋아한 일, 엔딩 종류 | 6문장 이내 편지(보슬비 엔딩은 아쉬움도 솔직하게) | 키운 방식이 반영된 나만의 엔딩 |

### 실패 처리 기준

| 상황 | 기준 | 사용자 안내 / 대응 |
|---|---|---|
| 빈 입력 | 말 걸기에 공백만 입력 | "강아지에게 할 말을 먼저 적어 주세요." (요청 안 보냄) |
| 지연 | 응답 대기 중 / 7초 이상 | 말풍선 "…" 표시 / "조금 오래 걸리고 있어요" |
| 타임아웃 | 브라우저 30초, 서버 25초 | "응답이 30초 넘게 오지 않아 멈췄어요" |
| API 오류 | Gemini 4xx/5xx | "AI 서버 오류가 났어요(코드 N)" |
| 사용량 초과 | 429 | "조금 쉬었다가 다시 시도해 주세요" |
| 형식 오류 | JSON이 깨지거나 항목 누락 | 서버가 거르고, 화면은 기본 이벤트·일기로 대체해 게임 계속 진행 |

### 테스트 케이스

| 입력 | 기대 결과 |
|---|---|
| 아기 강아지에게 "안녕?" | 서툰 말투의 짧은 답장, 말풍선에도 표시 |
| 배부름이 낮을 때 "기분 어때?" | 배고프다는 내용이 섞인 답장 |
| 빈칸으로 말 걸기 | 빨간 안내 문구, 요청 전송 안 됨 |
| 아기 → 꼬마 단계 변화 | 축하 연출 후 성장 일기 표시, 앨범에 저장 |
| 이벤트 선택지 클릭 | 결과 문장과 상태 변화 표시, 추억에 기록 |
| 무지개다리 후 편지 받기 | 추억이 반영된 편지 표시, 앨범에 저장 |

### 과제 예시와의 차이

과제 예시('멍냥케어')는 입력값에 맞춰 돌봄 정보를 추천하는 서비스입니다. 멍생일기는 한 강아지의 일생을 직접 키우는 시뮬레이션 게임이며, AI는 추천이 아니라 강아지의 목소리(대화·일기·편지)와 일상 사건을 만드는 데 쓰입니다.

## 5. 운영 고려사항

- API 키는 Vercel 환경 변수로만 관리, 코드·README·스크린샷에 노출하지 않음
- 무료 API 사용량 한도를 고려해 돌보기·놀기·훈련에는 AI를 쓰지 않음. 이벤트는 확률로만 발생, 성장 일기는 한 생애에 3~4번. 요청 후 1.5초간 버튼 비활성화
- 응답 속도를 위해 모델의 생각 단계를 최소(minimal)로 설정
- 사용자 입력은 서버에 저장하지 않음
