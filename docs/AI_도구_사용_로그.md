# AI 코딩 도구 사용 로그 — 멍생일기

- 사용 도구: Claude (Anthropic), claude.ai 채팅
- 진행 방식: 내가 기획·요구사항·피드백을 말로 전달 → Claude가 코드 작성, 브라우저 자동 테스트, 수정 → 내가 체험판으로 직접 플레이하고 다시 피드백
- 아래는 실제 대화의 주요 흐름을 정리한 것이다. "요청"은 내가 보낸 메시지(원문 그대로 또는 요약), "Claude 작업"은 그에 대한 결과다.

---

## 1. 기획

| 요청 | Claude 작업 |
|---|---|
| 과제 문서를 붙여 넣고 어떻게 해야 하는지 질문 | 제출물 5종과 역할 분담 정리, 무료 키가 있는 Gemini API 사용 제안 |
| "업무관련한거 말고 좀 귀여운걸로." | 귀여운 서비스 아이디어 3개 제안 |
| "강아지키우는 게임 하고싶어. 아기강아지부터 강아지가 무지개다리건너서 천국가는것까지" | '멍생일기' 기획: 페이지 4개(처음으로·키우기·추억 앨범·도움말), 생애 단계, AI 기능(말 걸기·하늘나라 편지), 실패 처리 설계 |

## 2. 첫 구현과 테스트

- 바닐라 HTML/CSS/JS + `api/dog.py`(Vercel Python 서버리스) 구조로 작성
- 가짜 AI 응답 서버를 띄워 브라우저 자동 테스트(입양 → 엔딩 → 편지, 데스크톱·모바일 화면)
- 테스트 중 발견해 고친 오류
  - CSS `display: grid`가 HTML `hidden`을 덮어써 엔딩 후에도 버튼이 보임 → `[hidden]{display:none!important}`
  - 받침 있는 이름에 조사가 틀림("봄가") → 받침 판별 함수 `josa()` 추가

## 3. 배포

| 요청 | Claude 작업 |
|---|---|
| "api 하기전에 나일단 게임해보고싶어" | 서버 없이 플레이할 수 있는 체험판을 따로 만들어 줌 |
| GitHub 업로드·Vercel 연결 과정에서 막힐 때마다 화면 캡처 전달 | 단계별 안내(커밋 4번 나눠 올리기, Application Preset 'Other', 환경 변수 `GEMINI_API_KEY`·`GEMINI_MODEL` 설정) |

## 4. 오류 ① 배포 후 AI 시간 초과

- 증상: 배포 사이트에서 말 걸기 → "강아지가 대답을 너무 오래 고민하고 있어요" (서버 시간 초과)
- 원인 분석: Gemini 3.x 모델이 기본으로 '생각(thinking)' 단계를 길게 거쳐 서버 제한 시간(20초)을 넘김
- 수정: `thinkingConfig.thinkingLevel=minimal`, 답변 길이 축소, 서버 25초·함수 30초(`vercel.json`), 설정을 모르는 모델이면 설정을 빼고 자동 재시도

## 5. 피드백 반복 개선 (체험판 v2 → v11)

직접 플레이하며 캡처와 함께 보낸 피드백과 반영 내용:

| 내 피드백 (요약) | 반영 |
|---|---|
| 게임이 단순함, 밥그릇·산책 연출, 짖는 소리, 표정, 어릴 때와 성견 구분, AI를 더 다양하게 | 동작별 애니메이션, Web Audio 효과음, 표정 9종, 단계별 체형, AI 기능 확대 |
| 글자가 얼굴을 가림, 모바일 세로 화면에서 반응이 안 보임 | 말풍선 위치 이동, 모바일에서 강아지 장면 상단 고정 |
| AI 이름 추천 빼기, 얼굴 선택, 평면적인 얼굴, 상점, 도파민 | 얼굴 4종, 입체 음영, 뼈다귀·상점, 콤보·황금 뼈다귀·공 잡기·업적 |
| 옷과 욕조가 이상함, 자라는 속도, 키운 결과에 따른 엔딩, 옆모습 | 옷을 몸에 맞게 자르기, 욕조를 그림 안으로, 성장 속도 조정, 엔딩 5종, 옆모습 걷기 |
| 도형을 붙인 것 같음, 산책 중 집이 그대로 있음, 대화의 재미, 퀘스트 | 털 질감 필터로 한 덩어리 실루엣, 장소별 배경, 대화 친밀도 게임, 퀘스트 |
| 퀘스트가 조잡함, 망토 옆모습, 코가 큼, 꼬리 흔들기 | 퀘스트 한 줄로, 망토 옆모습, 얼굴 비율 조정, 꼬리 애니메이션 |
| 옷이 몸보다 작음, 다리 어색, 울음소리, 오랜만에 오면 외로워하기, 시키지 않은 장난 | 몸 윤곽에 맞춘 옷, 걸음걸이, 귀여운 "왕!" 소리, 외로움·달래기, 혼자 하는 개인기와 사고 |
| 걸을 때 다리·발바닥 어색, 뼈다귀가 강아지마다 리셋돼야 함, 욕조가 작음 | 대각선 다리 걸음걸이, 발바닥이 다리와 함께 움직임, 새 강아지마다 뼈다귀 20개, 욕조 확대 |

각 버전마다 Claude가 브라우저 자동 테스트(입양부터 엔딩까지 전체 플레이, 모바일 화면)를 돌려 오류가 없는지 확인했다. 테스트 중 발견한 예: 뼈다귀를 받은 뒤 버튼이 멈추는 버그(문자열 일괄 치환으로 함수 안에 없는 변수가 들어감) → 원인을 찾아 수정.

## 6. 오류 ② 모델 속도 문제 해결

- 증상: 최신 코드를 올렸는데도 배포 사이트에서 계속 시간 초과
- 원인 분석: 코드가 아니라 무료 키에서 `gemini-3.8-flash`의 응답이 너무 느림
- 해결: 코드 수정 없이 Vercel 환경 변수 `GEMINI_MODEL`을 AI Studio에서 '가장 빠른 모델'로 안내된 `gemini-3.5-flash-lite`로 바꾸고 재배포
- 결과: 말 걸기에 정상 답장 확인(오늘의 주제 반영, 친밀도 상승) → 스크린샷 `ai_talk.png`

## 배운 점

- 환경 변수로 키와 모델을 분리해 두니, 모델 교체가 코드 수정·재업로드 없이 재배포만으로 가능했다.
- 로컬(가짜 응답) 테스트는 통과해도 실제 배포 환경에서는 외부 API 속도 같은 다른 문제가 생길 수 있다.
- AI가 만든 코드도 화면으로 직접 확인하고 구체적으로 피드백해야 원하는 결과가 나온다.
