# 멍생일기 🐶🌈

아기 강아지부터 무지개다리를 건너 하늘나라에 가기까지, 한 강아지의 일생을 함께하는 웹 게임입니다.
밥을 주면 밥그릇이 나와 강아지가 먹고, 산책을 가면 동네 풍경이 지나가요. 쓰다듬고, 짖게 하고, 재주를 가르치고, 말을 걸 수 있어요.
잘 키우면 뼈다귀(게임 화폐)가 쌓여 상점에서 집과 옷, 모자를 살 수 있어요. 콤보, 황금 뼈다귀, 공 잡기 미니게임, 업적 15종이 계속 하고 싶게 만들고, **어떻게 키웠는지에 따라 5가지 무지개다리 엔딩** 중 하나를 건넙니다.
AI는 대화(친밀도 게임), 성장 일기, 랜덤 이벤트, 하늘나라 편지까지 4곳에서 쓰입니다. 한 번에 하나씩 나오는 퀘스트가 할 일을 알려 줍니다.

- 배포 URL: https://mungsaeng-diary.vercel.app
- 서비스 기획서: [docs/서비스기획서.md](docs/서비스기획서.md)

## 주요 기능

| 페이지 | 내용 |
|---|---|
| 처음으로 (`index.html`) | 서비스 소개, 생애 단계 안내 |
| 키우기 (`game.html`) | 입양 → 돌보기·놀기·훈련 → 성장 → 무지개다리 엔딩 |
| 추억 앨범 (`album.html`) | 추억 타임라인, 성장 일기, 하늘나라 강아지와 편지 |
| 도움말 (`help.html`) | 자주 묻는 질문, 기록 초기화 |

### 입양
- **얼굴 4종**(축 처진 귀, 쫑긋 귀, 몽실 털, 얼룩 눈) × **털 색 3종**을 미리보기로 보며 고름

### 키우기
- **돌보기 5종 (시간이 흐름):** 밥 주기(밥그릇·냠냠), 산책(지나가는 풍경·목줄), 공놀이(날아오는 공·점프), 목욕(욕조·거품·부르르 털기), 낮잠(밤하늘·Zzz). 나이에 따라 효과가 달라요(노견은 산책이 버겁고 낮잠이 잘 들어요).
- **함께 놀기 (시간이 흐르지 않음):** 쓰다듬기(강아지를 직접 눌러도 됨), 짖어!(나이별로 다른 짖는 소리), 소리 켜기/끄기·음량 조절
- **훈련:** 앉아·손·엎드려. 기분이 좋을수록, 연습할수록 성공률이 올라가고 정해진 횟수를 채우면 재주를 배움
- **표정 9종:** 기본·신남·하트눈·시무룩·졸림·배고픔·먹는 중·놀람·짖음. 상태에 따라 자동으로 바뀌고 청결이 낮으면 흙 얼룩이 생김
- **단계별 모습:** 아기(큰 머리·짧은 다리) → 꼬마(반다나) → 어른(목걸이 이름표) → 노견(흰 눈썹·뜨개 조끼) → 하늘나라(후광·날개). 하늘 색과 배경 소품도 함께 바뀜
- **앞모습·옆모습:** 산책·공놀이 때는 옆모습으로 다리를 번갈아 걷고 달림. 가만히 있을 때도 가끔 옆으로 돌아봄
- **소품 연출:** 밥그릇은 강아지 발 앞에, 목욕은 다리 달린 욕조에 들어가 머리에 거품이 얹힘. 옷은 몸 모양에 맞게 입혀짐
- **성장 속도:** 첫 1년은 2개월씩, 이후 8개월씩(한 생애 약 20번 돌보기)
- **털 질감 그림:** 몸·머리를 한 덩어리 실루엣으로 그리고 SVG 필터(`feTurbulence`+`feDisplacementMap`)로 털이 보송한 가장자리를 만듦. 부드러운 음영(블러), 털결 선, 촉촉한 눈, 입체 코
- **장소 변화:** 밥은 부엌, 공놀이는 울타리 마당, 목욕은 욕실, 낮잠은 밤 침실, 산책은 지나가는 동네 풍경으로 배경과 바닥이 바뀜
- **모바일:** 강아지 장면이 화면 위에 고정되어, 아래 버튼을 눌러도 반응이 바로 보임. 말풍선은 얼굴을 가리지 않게 머리 위에 표시

### 살아 있는 강아지
- **시키지 않아도** 혼자 개인기(빙글빙글, 두 발로 서기, 우다다, 꼬리 쫓기, 하품, 갸웃)를 하고, 가끔 **사고**(응가, 쉬야, 양말 훔치기, 화분 파기, 슬리퍼 물어뜯기)를 침. 톡 눌러 수습하거나 혼낼지·봐줄지 고름. 40초 동안 안 치우면 청결이 떨어짐
- **오랜만에 오면 외로워함:** 마지막 방문 후 1시간 이상 지나면 시무룩한 얼굴로 낑낑거리고 배부름·행복이 줄어듦. 쓰다듬거나 말을 걸어 달래 주면(1~12시간 2번, 12시간 이상 4번) "보고 싶었어!" 하며 반가워함
- 눈 깜빡임, 숨쉬기, 꼬리 흔들기, 나이별로 다른 귀여운 "왕!" 소리와 낑낑 소리(Web Audio 합성)
- 옷은 몸통 실루엣을 그대로 따라 입혀지고 다리는 옷 밖으로 자유롭게 움직임(앞·옆모습 모두)
- 걸을 때는 대각선 다리끼리 짝을 지어, 땅을 딛고 뒤로 미는 동작과 발을 들어 앞으로 내딛는 동작을 번갈아 함

### 대화 게임
- AI가 답장과 함께 **감정**(표정이 바뀜)과 **다정함 점수(0~3)**를 매김 → 행복·친밀도·뼈다귀 증가
- **친밀도 레벨 5단계**(낯가림 → 친구 → 단짝 → 가족 → 영혼의 단짝), 레벨 업 보상
- **오늘의 주제:** 주제 단어를 넣어 말하면 보너스 뼈다귀, 주제가 새로 바뀜

### 퀘스트
- 한 번에 하나씩 한 줄로 표시(예: 밥 2번 주기, 오늘의 주제로 대화하기). 완료하면 보상을 받고 다음 퀘스트로 교체

### 보상과 상점 (계속 하고 싶게 만드는 장치)
- **뼈다귀 🦴:** 돌볼 때 상태가 좋을수록 많이 받음(1~6개)
- **콤보:** 지금 가장 필요한 돌봄을 고르면 콤보가 이어지고 보상 최대 3배
- **황금 뼈다귀:** 돌볼 때 8% 확률로 +30, 번쩍이는 연출
- **공 잡기 미니게임:** 공놀이 때 움직이는 공을 초록 구간에서 탭 → PERFECT/GOOD/MISS
- **업적 15종:** 달성하면 팡파레와 함께 알림, 보상 지급. 추억 앨범에서 확인
- **엔딩 5종:** 돌봄 점수(평생 평균 상태), 배운 재주, 최고 콤보, 많이 한 돌봄 종류에 따라 결정. 키우는 동안 "지금 가는 길" 예상 엔딩이 표시됨

| 엔딩 | 조건 |
|---|---|
| 🌟 황금 무지개다리 | 돌봄 점수 70 이상 + 재주 2개 이상 + 최고 콤보 3 이상 |
| 🌸 꽃길 무지개다리 | 돌봄 점수 55 이상 + 공놀이·쓰다듬기 위주 |
| ☁️ 구름 산책길 | 돌봄 점수 55 이상 + 산책 위주 |
| ✨ 별빛 무지개다리 | 그 밖의 경우 |
| 🌦️ 보슬비 무지개다리 | 돌봄 점수 45 미만 (편지에 아쉬움이 담김) |
- **상점:** 집 4종, 옷 4종, 모자·소품 4종. 산 물건은 장면과 강아지에 바로 적용. 뼈다귀는 강아지마다 20개로 새로 시작(산 물건은 유지)
- 기록은 브라우저 `localStorage`에 저장(회원가입 없음). 효과음은 파일 없이 Web Audio로 합성

## AI 기능 (POST `/api/dog`)

| mode | 언제 | 입력 | 출력 |
|---|---|---|---|
| `talk` | 말 걸기 | 보호자의 말 + 이름·나이·상태·오늘의 주제 | 답장 + 감정 + 다정함 점수 (JSON) |
| `diary` | 성장 단계가 바뀔 때 자동 | 이름·나이·최근 추억 | 강아지 시점 성장 일기 |
| `event` | 돌보기 4번마다 50% 확률 | 이름·나이·상태·최근 추억 | 상황 + 선택지 2개 + 결과·상태 변화 (JSON) |
| `letter` | 무지개다리 후 버튼 | 추억 목록·가장 좋아한 일·엔딩 종류 | 엔딩에 맞는 톤의 하늘나라 편지 |

흐름: 화면에서 `fetch('/api/dog')` → `api/dog.py`가 입력 검사 후 단계별 말투 규칙을 붙여 Gemini 호출 → JSON 응답을 검사·정리해서 반환 → 화면에 표시

### 실패 처리

| 상황 | 처리 |
|---|---|
| 빈 입력 | 화면에서 바로 안내(요청 안 보냄), 서버도 400으로 재확인 |
| 지연 | 응답을 기다리는 동안 말풍선에 "…" 표시, 7초 지나면 "조금 오래 걸리고 있어요" |
| 타임아웃 | 브라우저 30초 / 서버 25초에 중단하고 안내 |
| API 오류·사용량 초과 | 502/429로 변환해 안내 문구 표시 |
| AI가 형식이 틀린 JSON을 줄 때 | 서버가 검사해서 거르고, 화면은 준비된 기본 이벤트·일기로 대체해 게임이 멈추지 않음 |
| 과다 호출 | 요청 후 1.5초간 버튼 비활성화, 돌보기·시간 경과에는 AI를 쓰지 않음 |

## 환경 변수

API 키는 코드에 넣지 않고 Vercel 환경 변수로만 관리합니다.

| 이름 | 필수 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | 필수 | Google AI Studio에서 발급한 키 |
| `GEMINI_MODEL` | 선택 | 기본값 `gemini-2.5-flash`. 배포에서는 응답이 빠른 `gemini-3.5-flash-lite` 사용 |
| `GEMINI_THINKING` | 선택 | 기본값 `minimal`(응답 속도 우선). `off`면 설정을 보내지 않음 |

설정 위치: Vercel 프로젝트 → Settings → Environment Variables. 값을 바꾼 뒤에는 **Redeploy** 해야 반영됩니다.
로컬에서는 `.env.example`을 복사해 `.env`로 만들고 키를 넣습니다(`.env`는 `.gitignore`로 커밋 제외).
키가 노출됐다고 의심되면 Google AI Studio에서 즉시 키를 삭제·재발급하고 Vercel 환경 변수를 교체합니다.

## 실행 / 배포 방법

### 배포 (Vercel)
1. 이 저장소를 GitHub에 올린다.
2. vercel.com에서 GitHub로 로그인 → **Add New → Project** → 이 저장소 **Import**
3. Application Preset은 **Other**, Environment Variables에 `GEMINI_API_KEY`, `GEMINI_MODEL` 추가 → **Deploy**
4. 이후 GitHub에 커밋하면 자동으로 재배포된다.

### 로컬 실행 (선택)
```bash
npm i -g vercel
vercel dev        # http://localhost:3000
```

## AI 코딩 도구 사용과 오류 수정 기록

Claude(Anthropic)로 기획, 화면, 코드, 테스트를 진행했습니다. 대화 기록은 `docs/screenshots/`에 있습니다.

| 문제 | 원인 | 수정 |
|---|---|---|
| 생각 단계를 줄여도 배포 사이트에서 계속 25초 시간 초과 | `gemini-3.8-flash`는 무료 키에서 응답이 너무 느림 | 코드 수정 없이 Vercel 환경 변수 `GEMINI_MODEL`을 가장 빠른 `gemini-3.5-flash-lite`로 바꾸고 재배포 → 정상 응답 확인 |
| 배포 후 말 걸기가 "너무 오래 고민" 오류로 실패 | Gemini 3 계열 모델은 기본으로 '생각(thinking)'을 길게 해서 서버 제한 시간(20초)을 넘김 | `thinkingConfig.thinkingLevel=minimal` 지정, 답변 길이 축소, 서버 25초·함수 30초(`vercel.json`)로 조정. 모델이 설정을 모르면 설정을 빼고 자동 재시도 |
| 엔딩 후에도 돌보기 버튼이 보임 | CSS `display: grid`가 HTML `hidden` 속성을 덮어씀 | `[hidden]{display:none!important}` 추가 |
| 산책 배경이 강아지를 가림 | 배경이 효과 레이어(가장 위)에 들어가 있었음 | 배경 전용 레이어(`#scene-back`)를 강아지 뒤에 추가 |
| 받침 있는 이름에 조사가 틀림("봄가") | 조사를 고정 문자열로 붙임 | 받침을 판별하는 `josa()` 함수 추가 |
| 모바일에서 말풍선이 얼굴을 가림 | 말풍선이 장면 중앙에 겹쳐 배치됨 | 말풍선을 머리 위 영역으로 옮기고 강아지 크기를 장면 높이에 맞춤 |
| 모바일에서 버튼을 누르면 강아지가 화면 밖 | 세로로 긴 한 줄 배치 | 장면을 화면 위에 고정(`position: sticky`) |
| 강아지가 도형을 붙인 것처럼 보임 | 원·타원마다 따로 윤곽선과 그라데이션을 넣어 경계가 드러남 | 몸을 한 덩어리로 묶고 털 필터로 가장자리를 처리, 음영은 블러로 부드럽게 |
| 옷을 입으면 옆모습에서 몸통이 옷 밖으로 삐져나옴 | 옷을 고정 크기 사각형에서 잘라 만들어 몸통보다 작았음 | 몸통 윤곽선을 그대로 따라 그리고 살짝 크게 덮도록 변경 |
| 걸을 때 발바닥이 다리와 따로 놂 | 발바닥 무늬가 다리와 별개로 고정돼 있었음 | 발바닥을 각 다리 안에 넣어 함께 움직이게 함 |
